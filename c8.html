신경망과 선형 연산자
  • external operator(외부 연산자): 관련 필드들 사이의 mapping — 입력 가 출력으로 사상된다
  • 이미지는 2D 행렬(x축, y축 위의 intensity) — grayscale(그레이스케일) = 2D intensity(명암) 행렬
  • MLP(다층 퍼셉트론) 예: 입력 이미지 → 층마다 반복, 은 이전 층의 함수, 총 층 → 출력은 분류 라벨(예: "cat")
  • convolution(합성곱) 직관: 고양이 귀는 뾰족하고 개 귀는 둥글다 — 단 클래스 간에도 작은 상관은 남을 수 있다
