문제 2

는 전혀 관측되지 않고 의 일부만 있을 때 를 추정하는 두 네트워크 방법을 AI 도구와 함께 설계하라. 먼저 네트워크 는 에서 를 예측하고, 두 번째 네트워크 는 에서 를 예측한다. 합성 네트워크는 ⁠.

  1. [10점] HW3과 같은 분석을 수행하라: 전체 정확도를 구하고 vs ⁠, vs 그래프와 Pearson 상관계수를 계산하라.
  2. [10점] 수열이 항상 수렴하는지 논하고, 이 문제의 어려움과 개선 방법을 논하라.
유형: 구현 + 알고리즘 분석 문제 · g∘f의 고정점 반복이 왜 위험한지(축소사상 조건)를 먼저 묻는 문제
힌트
  • 이면 진짜 값은 고정점(fixed point)⁠. 반복 수렴 조건은 spectral radius(스펙트럴 반경) ⁠. 학습 손실에 없는 조건이다.
  • Newton method(뉴턴 방법)⁠: 은 반발 고정점에도 수렴 가능.
정답

설정은 HW3 5번과 같다. 900개 조합에 대해 SIR을 풀었다(HW3에서 고친 RK3, ⁠). 불완전 자료: 는 전혀 관측되지 않고 는 세 값만 있다고 가정. 두 네트워크 모두 은닉층 하나(sigmoid 100개)와 선형 출력층.

입력·출력을 학습 자료 기준으로 표준화하고 Adam으로 40000번 학습(720/180 분할, 시드 0). 시험 자료에서 의 평균 절대오차는 명.

STEP 1(1) 세 가지 평가
  • (A) 진짜 를 에 넣고 를 한 번 통과: 정확도 99.81%, 99.79% (Pearson 0.99999 / 0.99986). 이것은 가 각자 잘 학습되었다는 것만 보여준다. 진짜 값을 이미 알아야 쓸 수 있다.
  • (B) 실제 설정: 로 두고 구간 중앙 에서 고정점 반복(변화량 이면 정지): 정확도 65.16%, −127.3%(상대오차 227%로 음수).
    • 반복은 180개 모두 평균 18.5번 만에 수렴했지만 진짜 값으로 간 경우는 하나도 없었다.
    • 수렴점 180개 모두 학습 구간 밖이고, 는 0.3 근처나 −0.16 근처의 두 띠로 갈라졌다(음수 는 물리적으로 무의미).
  • (C) Newton 법 + 구간 안 자르기(아래): 정확도 97.4%, 95.3%.
  • (비교) 만 넣고 바로 추정: 99.74%, 99.10%.
STEP 2(2) 수렴 보장과 어려움

수열이 수렴한다는 보장은 없다. 학습에 contraction(축소사상) 조건이 전혀 들어가지 않기 때문이다. 수렴해도 진짜 값으로 간다는 보장도 없다(이번에는 모두 수렴했지만 모두 틀린 점).

진짜 값에서 의 Jacobian(야코비안)을 finite difference(유한차분)으로 구해 보니 스펙트럴 반경이 180개 중 173개에서 1보다 컸다(중앙값 1.70, 최대 2.52). 고윳값 하나는 0에 가깝고(중앙값 0.078) 다른 하나는 1.6~2.5. 따라서 진짜 고정점은 반복을 밀어내는 점이고 바로 옆에서 시작해도 멀어진다. 실제로 도착한 점들에서는 스펙트럴 반경이 모두 1보다 작았다(0.04~0.63). 에 학습 범위 밖의 가 들어가서 생긴 가짜 고정점이다. 시작점을 구간의 네 귀퉁이로 바꾸면 82~157개만 같은 점으로 가서 가짜 고정점이 여러 개임도 확인했다.

어려움의 본질: 학습 목표(진짜 값을 다시 진짜 값으로)와 반복이 요구하는 성질(축소사상)이 다르다. 또 가 틀리면 는 주어진 와 맞지 않는 입력을 받고, 이런 조합은 학습 자료에 없으니 출력은 외삽이 된다. 자료 자체도 가 없고 가 세 값뿐이라 적다.

개선: 고정점 반복 대신 Newton 법으로 을 풀고 매 단계 값을 학습 구간 안으로 잘랐다. 그 결과 180개 중 166개가 평균 6.1번 만에 수렴, 그중 144개는 상대오차 1% 이내. 수렴한 166개만 보면 정확도 99.78%, 99.15%, 미수렴 14개 포함이면 97.4%, 95.3%다. 미수렴 14개 중 10개는 값이 구간 경계에 걸려 멈춘 경우다. 학습 방식 개선으로는 틀린 에서 만든 도 학습 자료에 넣어 축소사상을 유도하거나, 손실에 SIR 방정식을 넣는 방법이 있다. 참고로 세 값만으로 바로 추정해도 99% 이상이었다. 성능을 떨어뜨린 것은 두 네트워크를 반복으로 연결한 방식이었다.

(A) 진짜 값으로 한 번 통과: 거의 완벽 (재현 실행). 하지만 이 방식은 진짜 값을 이미 알아야 한다

(B) 고정점 반복: 모두 수렴했지만 모두 틀린 점(학습 구간 밖의 가짜 고정점)으로

(B) 반복에 따른 오차: 처음 몇 번은 가까워지다가 다시 멀어져 틀린 값에 머문다 (로그 스케일)

합성 네트워크의 고정점 반복은 축소 조건 없이 학습되므로 가짜 고정점으로 간다. Newton 법이나 직접 추정이 낫다.
